Meta Quest 3 での閲覧・保存のヒント
  • WebXR VR表示（左右眼独立レンダリング）： Three.js WebXRパイプライン（renderer.xr.enabled = true + renderer.setAnimationLoop）で左目（eye 0）と右目（eye 1）にそれぞれ専用の左眼・右眼テクスチャ/SBS半面を割り当て、二重像やぶれを防止します。HTTPSまたはlocalhost環境でご利用ください。
  • 全画面SBSビューア： WebXR非対応環境やブラウザ単体での視聴時に、左右並列（SBS）を画面いっぱいに表示します。右パネルからSBS画像を保存してQuest 3のギャラリーや立体ビューアアプリで開くことも可能です。
  • 深度推定アルゴリズム： 輝度・エッジ強調・中央フォーカス・周辺減衰を組み合わせ、被写体が快適に融像しやすい奥行きで立体化します。
